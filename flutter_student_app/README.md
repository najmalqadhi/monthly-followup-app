# تطبيق المتابعة الشهرية - كود تطبيق أندرويد (Flutter)

هذا المجلد يحتوي على الكود المصدري الكامل والمتوافق للفتح والتشغيل والنسخ المباشر إلى **Android Studio**.

---

## 1. متطلبات التشغيل

- **Flutter SDK:** الإصدار 3.19.0 أو أحدث.
- **Android Studio:** الإصدار Hedgehog أو Iguana أو أحدث، مع تثبيت Android SDK 34.
- **جهاز هاتف أندرويد حقيقي أو محاكي (Emulator)** بنظام Android 8.0 فأحدث.

---

## 2. خطوات الفتح في Android Studio

1. افتح برنامج **Android Studio**.
2. اختر **Open** ثم حدد هذا المجلد `flutter_student_app`.
3. انتظر حتى يكتمل فحص ملف `pubspec.yaml` وقم بالضغط على **Pub get** (أو نفذ الأمر في الطرفية `flutter pub get`).
4. اختر جهاز أندرويد المستهدف من شريط الأجهزة.

---

## 3. إعداد الاتصال بالخادم المحلي لجهاز المسؤول

1. تأكد من أن هاتف الطالب وجهاز كمبيوتر المسؤول متصلان بنفس شبكة الـ Wi-Fi المحلية.
2. لمعرفة عنوان IP لجهاز المسؤول في نظام Windows:
   - افتح موجه الأوامر `cmd` واكتب `ipconfig`.
   - انسخ عنوان IPv4 (مثال: `192.168.1.105`).
3. في تطبيق الطالب، عند شاشة الدخول اضغط على زر **«إعدادات الاتصال بجهاز المسؤول»**:
   - أدخل العنوان: `http://192.168.1.105:3000`.
4. عند انقطاع الاتصال أو إغلاق كمبيوتر المسؤول:
   - يعمل التطبيق في وضع **العمل دون إنترنت (Offline Mode)** تلقائياً.
   - تُحفظ كافة المسودات في الهاتف ولا تُفقد أبداً، وتتم المزامنة فور عودة الاتصال.

---

## 4. بناء ملف APK وتثبيته مباشرة على الهواتف دون Google Play

لتوليد ملف APK جاهز للتثبيت والتوزيع عبر واتساب أو فلاشة أو عبر الشبكة:

```bash
cd flutter_student_app
flutter pub get
flutter build apk --release
```

سيتوفر ملف التطبيق في المسار:
`build/app/outputs/flutter-apk/app-release.apk`

يمكن إرسال هذا الملف وتثبيته على أي هاتف أندرويد مباشرة بعد تفعيل خيار "تثبيت التطبيقات من مصادر غير معروفة" في إعدادات الهاتف.

---

## 5. تشغيل الاختبارات الآلية

```bash
flutter test
```
تم التحقق من نجاح كافة اختبارات محرك الدرجات وسقوف المحاور.
